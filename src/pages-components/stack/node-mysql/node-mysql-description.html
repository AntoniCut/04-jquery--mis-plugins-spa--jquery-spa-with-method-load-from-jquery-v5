La misma lectura, por Express

Express ejecuta la consulta contra jquery_mis_plugins_spa con el usuario jquery_user. El formulario envía la sentencia a api/mysql/query, relativo al <base> del sitio.

pnpm dev monta ese router. En el VPS lo sirve jquery-node detrás de Nginx, en el mismo prefijo del <base>. pnpm preview no lo monta: la página muestra el HTML de la SPA en el aviso, sin leerlo como JSON.

La página PHP con MySQL sigue hablando con app/services/mysql/query.php. Las dos comparten el contrato ok, message, columns y rows.
