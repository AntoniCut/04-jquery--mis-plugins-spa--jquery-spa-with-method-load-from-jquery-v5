Node con Express

CRUD REST en memoria sobre Node

Express corre dentro del servidor de desarrollo de este proyecto. pnpm dev monta el router en api/tasks, bajo el <base> del sitio. En el VPS lo sirve jquery-node. pnpm preview no levanta ese proceso.

El router es dueño de las rutas y del contrato JSON, mientras que el middleware en cadena mide la latencia, responde la cabecera X-Response-Time y registra una línea por petición.

Las tareas viven solo en memoria: no hay base de datos. Si el proceso Node se reinicia, la lista vuelve a las 3 tareas semilla originales.

Qué aporta este router

Router propio

createTasksRouter() devuelve un express.Router montable, separado del router de MySQL.

Middleware en cadena

Un primer middleware cronometra cada petición y un handler final responde los errores de body-parser.

Códigos HTTP explícitos

200, 201, 400, 404, 405, 413 y 422: cada caso tiene su respuesta JSON y su cabecera Allow.

Rutas del API

  • GET /api/tasks
  • POST /api/tasks
  • DELETE /api/tasks/:id
  • express.Router
  • express.json 4 KB
  • X-Response-Time
  • 405 Allow
